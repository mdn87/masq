The codebase itself doesn't use anything obviously Node-18-only (no `structuredClone`, `.at()`, `Object.hasOwn`, `fetch`, etc.), so it likely runs fine under Node 16 in practice — but it's not a supported/tested target, and Claude Code plugins generally expect whatever Node version Claude Code itself bundles. I'd stick to Node ≥18 as declared unless you have a specific reason to run 16.
