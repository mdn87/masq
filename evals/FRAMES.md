# Frames and their failure modes

Every measurement here sits inside a frame — a set of things taken as given in
order to look at something else. A frame is not a mistake; you cannot measure
anything without one. The failure mode is that a frame is invisible from inside
it, so effort spent on rigor goes into the part you can see.

This directory has now produced four wrong published results. Every one came from
a frame, not from carelessness inside it, and each was corrected by an outside
question rather than by more work.

## The pattern

| Round | What I added | What it fixed | What it could not see |
| --- | --- | --- | --- |
| 1 | more samples | a 4/4 fluke read as a fix | the criterion |
| 2 | a consistent criterion | two arms scored differently | the scoring loop |
| 3 | mechanical scoring | hand-count drift | the transport |
| 4 | adjudicated labels + statistics | proxy/judgement mismatch | still unknown |

Each round made the previous round's number more defensible. None of them
questioned the frame the number lived in. **Rigor compounds inside a frame and
does nothing across frames** — a more precisely measured artefact is still an
artefact, and looks more trustworthy for having been measured well.

## The frames, ordered by distance from the observable

The ones that bit hardest are the ones furthest from the thing being looked at.

### 1. The generation frame — broke, expensively

**Assumes:** what masq composes is what the model reads.
**Blind to:** the host. Claude Code replaces hook context above ~10,000
characters with a preview and a file reference.
**Produced:** `composition/01`. Thirty-one runs, three fix attempts, a length
correlation, a slot-order theory, and a policy/conduct asymmetry, all explaining
truncation. Two mechanisms were reverted for "doing nothing"; they could not have
done anything. The fixture explicitly cited 11,182 generated bytes as evidence
"the model received both profiles."
**Broken by:** putting a distinctive string in the payload and asking for it
back. Under the limit 5/5, over it 0/3, p = 0.018.
**Now:** `MAX_CONTEXT_CHARS` and a budget test. Delivery is checked for one case
and is still not part of the fixture format.

### 2. The success-shaped frame — broke, same event

**Assumes:** if the expected behavior is absent, the profile failed.
**Blind to:** every other cause of absence — the instruction not arriving, the
prompt not eliciting it, the criterion not matching it.
**Produced:** the whole composition narrative. Absence was read as suppression
and never as non-delivery. The same frame produced `de-tell/01`, where a rule was
called dormant when the fixture had simply failed to elicit the pattern.
**Breaker:** for any "the profile failed" verdict, enumerate what else produces
the same absence before writing it up.

### 3. The self-adjudication frame — broke twice

**Assumes:** whoever writes the criterion can apply it.
**Blind to:** their own priors, and to the gap between a criterion and its proxy.
**Produced:** the 0/9-versus-9/22 comparison, where the two arms were scored on
different criteria in the direction that flattered my fix. Then `audience/01`'s
"3/3 novice, 0/3 expert" glossing claim, which came from reading one run per arm
and generalising — on adjudication it is 2/2 versus 0/2 with three runs *unclear*.
**Broken by:** a reviewer, both times. Not by more of my own effort.
**Now:** per-run labels with rationales in `labels.json`, and an `unclear` label
so a blunt criterion is visible instead of forced into a binary.

### 4. The point-estimate frame — broke on contact with statistics

**Assumes:** 3/3 versus 0/3 is a result.
**Blind to:** sampling error at n=3.
**Produced:** essentially every verdict in this directory.
**Broken by:** printing Wilson intervals and Fisher exact p by default.

This one is worth stating in full, because it changes what the directory claims:

| Comparison | Rate | p |
| --- | --- | --- |
| delivery under vs over the limit | 5/5 vs 0/3 | **0.018** |
| delivery after budget vs over | 5/5 vs 0/3 | **0.018** |
| `conduct` stops an unrequested edit | 3/3 vs 1/3 | 0.400 |
| `de-tell` removes the preamble | 3/3 vs 0/3 | 0.100 |
| `plain`'s same-clause rule | 3/3 vs 0/2 | 0.100 |
| `audience` glossing dial | 2/2 vs 0/2 | 0.333 |
| policy under a register | 3/3 vs 1/2 | 0.400 |
| conduct composed vs alone | 16/16 vs 4/4 | 1.000 |

**Only the transport findings are significant.** Not one profile has been shown
to change behavior at p < 0.05. Every "pass" in this directory is a point
estimate at n=2–3 that happens to point the right way. Several probably are real
— 3/3 versus 0/3 on an unambiguous binary is suggestive, and the preamble result
would clear significance at n=5 per arm if it held — but suggestive is the honest
word and none of the fixtures used it.

### 5. The single-turn frame — unbroken, and known to be load-bearing

**Assumes:** a fresh `claude -p` session represents use.
**Blind to:** turn 2 onward, resume, compaction.
**Produced:** a claim that requirements were "lost after the first prompt", which
was wrong — SessionStart context persists in the transcript and SessionStart
re-runs on resume. The error was in the opposite direction to the frame's usual
bias, which is luck rather than method.
**Status:** every one of the 186 runs is turn 1. Multi-turn behavior has never
been observed.

### 6. The text-output frame — partially broken

**Assumes:** the response text is the behavior.
**Blind to:** tool side effects, and what the model actually received.
**Produced:** `conduct/01`'s first verdict, from an answer reading "Fixed —".
Salvaged only because a later run captured a file diff, which turned an anecdote
into the one non-text observable in the directory.
**Status:** one fixture captures a side effect. The rest read prose.

### 7. The marginal-effect frame — unbroken, and cannot be broken here

**Assumes:** the baseline arm is uninstructed.
**Reality:** the machine's global `CLAUDE.md` loads in both arms and already
encodes several of the habits under test.
**Blind to:** absolute effect. Every number here is marginal.
**Why unbroken:** isolating it requires `CLAUDE_CONFIG_DIR`, which relocates the
credentials and logs the CLI out.

## What a fixture has to assert now

The first three are new, and each exists because its absence produced a wrong
published result.

1. **Delivery.** State the emitted context size, and for anything near the limit,
   show the payload arrived.
2. **Alternative causes of absence.** Before concluding a profile failed, name
   what else produces the same absence and say which were excluded.
3. **Significance.** Quote the interval and the p-value, and say "suggestive"
   when it is suggestive.
4. Prompt, stacks, environment, expected, forbidden, verbatim outputs, verdict,
   residual ambiguity — as before.

## The thing that does not generalise

Each of these frames was broken by someone asking a question from outside it. The
sequence — more samples, consistent criteria, mechanical scoring, adjudicated
labels — is a good sequence and it never once found the frame it was operating
in. Three of the four corrections came from a cross-review; the fourth came from
computing something I had been assuming, and immediately overturned a banner I
had written minutes earlier claiming `afterdark renfaire` was truncated when it
was 9,111 characters and fine.

The practical form of that: the checks above are worth adding, and adding them
will not find frame 8. Nothing in a fixture format can. What finds a frame is a
reader who does not share it, which makes the cross-review the load-bearing part
of this method and everything else bookkeeping.
